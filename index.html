アプリケーション設定

Google Cloud Console で「OAuth 2.0 クライアント ID（ウェブ アプリケーション）」を作成し、「承認済みの JavaScript 生成元」に以下のオリジンを登録してください。
現在の登録用オリジン:
⚠️ 「エラー 400: origin_mismatch」や「401: invalid_client」の解決手順
🚨 エラー 400: origin_mismatch が出る場合:
  • Google Cloud Console の「承認済みの JavaScript 生成元」に、上記の「現在の登録用オリジン」が登録されていません。
  • GitHub Pages の場合: https://momijimugi.github.io
  • ローカル実行の場合: http://localhost:5173
  • ※末尾のスラッシュ / や /calendar は含めないでください！「http(s)://ホスト名(:ポート)」の形式で登録する必要があります。
  • 追加・保存後、Google側に反映されるまで2〜5分程度かかります。
⚠️ その他の確認項目:
  • アプリケーションの種類: 「デスクトップ」ではなく必ず「ウェブ アプリケーション」で作成してください。
  • 入力文字列: xxxx.apps.googleusercontent.com 形式です。APIキー（AIzaSy...）と混同していないか確認してください。
  • テストユーザー: OAuth同意画面が「テスト中」の場合、ログインするGoogleアカウントを「テスト ユーザー」に追加してください。
